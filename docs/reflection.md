# Reflection

This project introduced me to polyglot persistence, where multiple database technologies are used together to solve different problems. MongoDB, Redis, and PostgreSQL each provide unique strengths.

MongoDB is useful for storing flexible document data. Redis provides very fast in-memory operations and supports caching, leaderboards, and messaging. PostgreSQL with pgvector supports semantic search using vector similarity.

One of the biggest lessons from this project is that no single database is perfect for every task. MongoDB handled product storage, Redis improved performance and real-time communication, and PostgreSQL enabled advanced search capabilities.

The most interesting component was pgvector because it demonstrated how modern AI-powered search systems work. Overall, this project improved my understanding of database architecture and polyglot persistence.
